医院建设项目环保审批合规预审

辅助预审，不构成法律意见。材料默认留在你自己的电脑上。程序不会把没核对过的法规当成已经生效。

下载 Windows 压缩包

适用 Windows 10 和 Windows 11。解压后双击 启动（无需Docker）.bat。第一次会安装运行所需的 Python 库，然后打开浏览器。

  1. 安装 Python 3.11 或更高版本，勾选 Add python.exe to PATH。
  2. 解压压缩包，双击启动脚本。
  3. 在工作台里上传法规文本，或让程序去公开网站核验种子清单。看到的日期和状态码，请再对照官网点一次确认。

如果电脑里已经有 Docker Desktop，可以改用 启动（Docker）.bat。那一条使用 PostgreSQL。

它现在能做什么

把法律、法规和标准收进本机库，按条切开，并留下核验报告。数值规则由程序比较，不交给对话模型。引用必须能在原文里逐字对上。

国标全文请自己上传。消防、用地、医疗机构执业许可、地方标准不在这版范围内，遇到这些事项会标明范围外。

只有你以后自己配置了 DeepSeek 密钥，并运行参数抽取或定性判断时，相关文字才会发送到 DeepSeek。法规核验这一步不调用模型。
