本地运行

暂仅支持 Windows。

点下去之后，浏览器会问要不要打开 elaw。这是系统提示，选打开即可，也可以勾选始终允许。

没反应？下载安装包。安装包已自带 Python，解压后不用再装。装好后也可以从桌面的「环评合规预审」打开。

旧版 Word（.doc）需要本机另装 LibreOffice。模型密钥在本机工作台里自己填写，不会做进安装包。没有打开外发时，程序不会把报告片段送去接口。
